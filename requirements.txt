# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# pdfplumber>=0.11 :-
# Purpose: Extracts text, tables, and metadata from PDF files with high accuracy.
# Use case: When a candidate uploads a resume in PDF format, you can pull out the text and structured data (like tables or columns).

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# PyPDF2>=3.0 :-
# Purpose: General PDF manipulation — splitting, merging, rotating, encrypting, or extracting metadata.
# Use case: If you need to handle resumes beyond just text extraction (e.g., merge multiple PDFs, split pages, or check metadata).

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# python-docx>=1.1 :-
# Purpose: Read and write Microsoft Word .docx files.
# Use case: Many resumes are submitted in Word format. This library lets you extract text, headings, and styles, or even generate .docx reports.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# python-magic>=0.4.27 :-
# Purpose: Detects file type by inspecting its binary content (not just the extension).
# Use case: Ensures the uploaded file is really a PDF, DOCX, or TXT — and not mislabeled or malicious.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# jinja2>=3.1 :-
# Purpose: Jinja2 is a templating engine for Python.
# It lets you write HTML (or text) templates with placeholders that get filled dynamically.
# Use case in ATS: You can design a resume report template (HTML) and inject candidate data, scores, and feedback into it.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# weasyprint>=60.0 :-
# Purpose: WeasyPrint converts HTML + CSS into PDF documents.
# It’s like a headless browser that renders HTML/CSS and outputs a PDF.
# Use case in ATS: After generating an HTML report with Jinja2, you can use WeasyPrint to export it as a professional PDF for download or sharing.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# httpx>=0.27 :-
# Modern async HTTP client for Python.
# Used to make REST API calls efficiently (non‑blocking).
# In your case: acts as the Supabase REST client, letting you query Supabase tables, auth, and storage asynchronously.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# groq>=0.13 :-
# Client library for Groq LLMs (Large Language Models).
# Version 0.13+ is required because it ensures compatibility with newer httpx versions (>=0.28).
# Lets you integrate Groq’s AI models for tasks like resume scoring, text analysis, or feedback generation.

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# PyJWT[crypto]>=2.8 :-
# Handles JSON Web Tokens (JWTs).
# Supabase issues JWTs for authentication.
# This library verifies tokens (e.g., HS256 algorithm) to ensure requests are secure.
# [crypto] extra adds cryptographic support (via cryptography package).

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# requests>=2.31 :-
# Classic synchronous HTTP client.
# Simpler than httpx, often used for quick API calls (e.g., fetching job descriptions, external APIs).
# Useful when async isn’t needed

# ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
# supabase>=2.4 :-
# Official Supabase Python client.
# Provides higher‑level abstractions over REST calls (auth, database queries, storage).
# Easier than using raw httpx for common Supabase operations.
